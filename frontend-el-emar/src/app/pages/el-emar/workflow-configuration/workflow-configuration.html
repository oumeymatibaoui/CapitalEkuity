Principe Le modèle est global. Une candidature déjà initialisée conserve son propre circuit. Vous pouvez ajouter autant d'étapes libres que nécessaire et placer les quatre étapes métier à l'endroit souhaité dans le circuit.
Mode consultation — Administrateur Achat Vous voyez tout le workflow mais vous ne pouvez ni ajouter, ni supprimer, ni réordonner, ni renommer une étape, ni changer le modèle global. La seule écriture autorisée est la réaffectation d'un responsable dans un dossier.
4 types métier doivent exister avant l'enregistrement Recevabilité administrative, Évaluation technique, Décision finale et Classement par zone. Leur ordre est libre, mais leur département métier reste protégé afin de ne pas casser les contrôles backend.
